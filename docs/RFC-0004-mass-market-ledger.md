# RFC-0004：从「弹卡」转向「可分享的证据账本」（大众化路线）

- 状态：**Proposed** —— Accepted 的前提是 §6·M0 的回放数据落地（RFC-0003 的 Phase 0 至今没做，本 RFC 把它排在一切新功能之前）
- 日期：2026-09-19（基于 v0.2.0 代码库状态）｜ 关联：取代 RFC-0003 §7「投递策略」的讨论方向；保留其 §4 数据模型与 §3 回合边界
- 取证：本机实测 + 读码静态审计，逐条分级见 §11
- 出处：本文是 `readback` 的第 0 号文档。**正文里的 `file:line` 与 RFC-0003 均指向前身仓库 KVBA v0.2.0**（私有，已转只读参考实现）。刻意不改写成"本仓库某处"，是因为那些行号就是结论本身的证据——删掉指针，下一级就退化成"作者说过"。旧仓 `ddcbf4f` 及之前可按行号取到原文。

## 1. 决策摘要

主产物从**屏幕上的一张卡**改为**一份可分享、可存档、可进代码评审的报告**；判断权从 LLM 收回给确定性规则；接入从"必须挂宿主钩子"倒转为"读 git 与本地记录即可开工"。

定位一句话：**给 AI 写的代码装一个引擎故障灯**——不替你开车，只告诉你哪一段你没法解释、且从没被验证过。

| # | 现在 | 目标 | 为什么 |
|---|---|---|---|
| R1 | 实时门控 + 胶囊弹卡 | 回合之后交产物：`.readback/report.md`、PR 摘要段、commit trailer、每日 digest | 大众不接受工作流被打断；产物可分享才自带传播 |
| R2 | LLM 判断什么算问题 | 确定性「缺陷形态目录」出判断，LLM 只写措辞 | 实测 5 张真 LLM 稿有 2 张含可证伪的错误事实；带证据的确定性结论 0 错 |
| R3 | 不接钩子就不开工 | 只用 git + 本地记录即可出报告，钩子降为实时增强 | 今天首卡要 5+ 步手工配置、重启会话、甚至自己 `cargo build` |

## 2. 依据

**2.1 商品化线。** 依赖"模型更聪明"的能力，模型升级即免费送（IDE 自带 agent 复盘、CI 自带 PR 摘要）。依赖**现场采集**的买不到：谁在何时对哪个文件做了什么、命令退出码是几、你有没有确认过。后者是 KVBA 唯一不可复制的资产，今天却只当中间产物用。
> 旁证（静态审计：搜索标题所得，未逐一试跑）：2026-06 起已有大厂开源的"AI 代码审查 CLI"（宣传 5 分钟接入）与多个 code-review graph / CodeFlow 类项目。所以**"会审代码"不是护城河**；空位是本地跨 Agent 的现场账本 + 复述机制。

**2.2 价值出现的形态。** 它真正有用的时刻不是教了知识点，而是**在被观察的项目里找出真缺陷**——天然归属是代码可信度，不是编程教学。

**2.3 硬数据**

## 3. 三原则 / 六不做

**原则（写进代码，不写进愿望）**
- **P1 无证据不出声**：断言携带 `Evidence{kind,reference,excerpt}`（`insight/mod.rs:68-74`，字段已就位），句中路径/行数/存在性出稿前对本地仓库对拍，对不上就不生成该句。现状只有 `debug_assert!`（release 不校验）→ 升级为闸门。
- **P2 产物优先**：主接口是文件与文本块；弹卡/通知降为产物的两个订阅者。
- **P3 零接线优先**：不编辑任何宿主的配置文件也能拿到八成价值。

**不做**：① 不再调门控阈值（25s/10min/20min/分数 40，`gate/mod.rs:18-30`）——那台机器使命已结束；② 4 路适配器冻结，不加第 5 路；③ 不给"弹卡"这个形态加戏——视觉工作是有的（§9），但预算全给标识与产物排印，不给胶囊动效；④ 不做通用编程教学（换成 M3 的"复述你自己的代码"）；⑤ 不降 `interrupts()`（`insight/mod.rs:99`）门槛去抬打扰率，打扰率下降是目标；⑥ 不要求用户编译任何东西。

## 4. 面向谁

| 类 | 谁 | 动机 | 消费口 |
|---|---|---|---|
| A | 一人开发者 / 接单者 | "客户问我这行干什么的，我 30 秒能答" | 每日报告 + `.readback/report.md` |
| B | 3–20 人团队 lead | "无验证证据的改动进不了 main" | PR 摘要段 + check |
| C | 接手者 / 新人 | 读账本比读 diff 快 | A 的副产物 |

先做 A+B（同一份产物两个消费口）。不服务：企业合规、IDE 插件用户、"想学编程的人"（§2.2）。

## 5. 形态：四层

```
L1 采集   新增 离线读取(git log + agent 本地记录)   ← 大众主入口
          复用 4 路钩子 + kvba.event.v1 + 指纹判重  ← 降为实时增强
L2 账本   复用 WorkUnit/ChangeSet/TestResult/Insight/Evidence
          替换 扁平 JSON → SQLite(补分支/成本/回合基线/unit 链/人工结论回指)
L3 判断   改造 gate/ 启发式 + insight::is_*_file → 缺陷形态目录(规则即数据)
          复用 复盘 §四 38 类真实形态作为目录种子
L4 产物   新增 readback report --md / PR 段 / commit trailer / 每日 digest
          降级 胶囊、托盘、系统通知 = L4 的两个订阅者
```

**L3 是关键**：一条规则 = `触发条件(纯函数) + 所需证据 + 严重度 + 呈现模板`，写成数据而非 Rust 分支，规则自带夹具。收益：目录能长大而不必重调阈值；**未经核对的句子在结构上无法生成**；命中数天然可统计（§8 的分母）。

## 6. 里程碑（顺序不可打乱，验收均可证伪）

- **M0 素材与地基**（先取数，不写新功能）：① 建回放语料（**主料**：自造 20 个含已知缺陷的快照仓库 + 本仓自己的 git 历史；**可选加料**：前身仓 47 commits 的 numstat/作者/消息，以及可得的真实 agent 记录。**前身仓历史不能当验收前提**：那 47 条连同导入锚点 `ddcbf4f` 至今只存在于一台机器上（2026-09-21 实测），把判据绑在它上面等于让 M0 无法被任何人复核）；② 证伪关键未知——转录的 `tool_result` 是否携带可解析退出码/`is_error`（判据：≥90% 的 shell 类调用能取到 0/非 0 → 则「零接线也带验证证据」成立；取不到则 L1 退 git-only，形态不变、M2 少一类规则）；③ SQLite 迁移 RFC（`work_unit/evidence/claim/human_answer`）；④ `gate/` 启发式逐条抄成规则清单，不改语义（已交付：`docs/M0-rules-inventory.md`，46 条；自查 `python docs/m0-inventory-check.py --self`）。**验收：`docs/replay-baseline.md` 给出候选规则的命中数与人工核对真阳率；没有这份数不许进 M2。** 进度（2026-09-21 改）：四项里只交付了 ④。**① 不再等真实转录**——主料换成自造快照仓库与本仓自己的 git 历史，本仓就能开工；只有 ② 仍等那份转录（取法见 `docs/BOOTSTRAP.md` §5），它是唯一卡住 L1 形态的未知。
- **M1 零接线安装**：单文件可执行 + `npx @readback/cli@latest` 写一个 git hook（post-commit 记账 / pre-push 出报告），无 API Key 也能跑。桌面版若继续发：签名 + 公证 + 自动更新三项补齐。**验收：两台干净机器从下载到看到首份报告 ≤3 分钟、编辑配置文件 0 次；做不到就砍安装包，只发 CLI + GitHub Action。**
- **M2 目录 v1（20 条规则）+ 报告**：**验收：对复盘 §四 已知形态回放命中 ≥70%、人工抽 20 条误报 ≤20%、报告中指向不存在文件或错误行数的断言 = 0**（对拍脚本须带负向对照，证明它自己能失败）。
- **M3 复述队列**（"学习模式"的大众说法）：每周从账本挑 N 条"你没确认过的 AI 变更"让你一句话复述，答错/跳过则保留加权。**验收：连续 4 周完成率 ≥30%，且完成率与跳过率负相关。**
- **M4 团队治理（付费面）**：政策即数据（如「无测试证据的 Agent 变更不得进 main」），顺带闭合至今悬空的 `RiskLevel::P0` 定义。

依赖：M0 →（M1 可并行）→ M2 → M3/M4。

## 8. 度量与风险

只看 4 个：**证据覆盖率**（→100%，结构保证）、**真阳率**（每月人工抽 20 条，≥80%）、**产物打开率**（报告被 `git add` / 贴进 PR 的次数，本机可测、零遥测）、**复述通过率**。废弃：日发卡数、单独看 `answer_rate`（分子计数会被它想度量的故障喂饱——复盘 §四末行）、门控放行率。

| 风险 | 退出判据 |
|---|---|
| 目录只命中"我早知道了"的问题 | 连续两版报告被真实用户评为无新增信息 → 撤判断层，退成**纯账本**（存档+检索+成本归属），产品仍成立 |
| 转录字段不稳、退出码取不到 | M0·② 失败 → L1 退 git-only |
| 签名/公证/更新通道要钱 | 拿不到预算 → 只发 CLI + Action，不发安装包 |
| 读本地记录引发隐私质疑 | 默认全本地 + 一条命令列出"读了哪些路径" |
| **单人摊子过大（最大）** | 任一里程碑跨 6 周仍无可演示产物 → 每里程碑可单独发布；M0/M1 各只做一件事 |

## 9. 视觉与标识（随改名一并可换）

大众产品的第一视觉面是**那份文件**，不是那个窗口——报告会被贴进 PR、被同事读到，它才是传播面。

| 交付物 | 内容 | 取舍 |
|---|---|---|
| 标识族 | 字标 + 主图标 + 三平台安装包图标（.ico/.icns/256px）+ 托盘 glyph（16/22px 单色两态） | 新增；一次做完，之后不再动 |
| 报告排印 | 报告的 markdown/HTML 版式：结论行、证据引用块（可折叠）、严重度色板、深色模式 | 新增，优先级高于一切窗口 UI |
| 状态语义 | 现有三态 `idle`/`active`/`popup`（实测 `windows.rs:396`）重映射为三档：静默 / 有账可查 / 有事要你看；删掉徽标计数与面板内翻页等"阅读器式"装饰 | 语义收敛，不新增态 |
| 仓库门面 | README banner、OG 社交卡、CLI `--version` 的 ASCII 标 | 新增 |
| 胶囊皮肤与动效 | 保留现状尺寸与配色，仅换成新 glyph | 冻结 |

两条纪律：

- **像素层也受 P1 约束**：任何视觉元素不得表达"未经核对的确定性"——不给无证据的条目画绿色对勾，不用"✓ 已验证"这类图标语汇。上一版卡片里 2/5 含假事实的教训，换个皮肤照样会犯。
- **语言双轨从第一天起**：现有文案全中文硬编码（含 `SettingsView` 提示语），"面向大众"必然要求英文优先 + 中文并列；改名与换图标若不连带解决 i18n，等于把孤岛换了个名字。

## 10. 新仓库与命名

**命名判据**：① 不含任何宿主名（`claude-*` 会把跨 Agent 定位一次性卖掉）；② 能做二进制名与 CLI 动词；③ 说得出产品的核心动作，不是抽象比喻；④ 与既有同域项目不撞车（已排掉 `receipts`：GitHub 上存在 `chrishutchinson/claude-receipts`，同处相邻语义，会被读成仿作）。

**推荐：`readback`**（回读）——无线电/航空规程里"接收方把指令复述一遍以证明听懂"的那一步，正是本产品的核心机制（§6·M3）与核心主张（你得能解释你要发的代码）。落法：仓库 `readback`，二进制 `readback`，产物 `.readback/report.md`，安装 `npx @readback/cli@latest install`（npm 裸名已被占，见下）。
备选：**`blindspot`**（痛点框架，一眼懂，缺点是只讲问题不讲做法）；**`witness`**（证据框架，沉稳，缺点是搜索噪音大、npm 同名概率高）。
> **占用核验已做（2026-09-21 实测；命令与原始输出见 `BOOTSTRAP.md` §1 结果表）——原文那句"npm 与 crates.io 探测被 403 与反爬挡住，本机无法定论"已作废。** 结论：三个候选名在两个 registry 上**全部被占**。
> - `blindspot`：npm 是"扫 Node 项目缺哪些常用工具"的 DX CLI，crates.io 是"装/更新单二进制应用"的安装器——**两处都是同域项目**，按本节判据 ④ 直接出局（与 `receipts` 同一理由）。
> - `witness`：npm 0.0.2（词典义占位）、crates.io 0.3.0（文件监视器）——本节预判的"npm 同名概率高"被证实。
> - `readback`：npm 是航空管制通话转写（`borisdiakur/readback`，keywords atc/vatsim/ivao），crates.io 是 Tauri IPC 库的**占名预留**（`0.0.0 # This release reserves the crate name`）。两者都**不构成仿作风险**（不同域），但裸名都用不了。
>
> 处置：**仓库名与二进制名不变**（GitHub 仓名按用户命名空间，不受 registry 占用影响）；npm 退作用域名 `@readback/cli`；crate 若发则用 `readback-cli`（实测未占）。注意 `@readback/cli` 能否成立取决于 npm 上是否存在名为 `readback` 的用户/组织——`npmjs.com/~readback` 本机返回 403，**这一条仍未验证**，须由人登录后核（`BOOTSTRAP.md` §1）。GitHub 侧两条核验（`gh search repos` / `gh api /users/readback`）本机被沙箱策略挡住，同样未做。

**迁什么、留什么**

- 迁：`insight/`+`workunit/` 数据结构与其 109 项单测、`gate/` 抄出的规则清单（M0·④）、`kvba.event.v1` 事件契约、4 路适配器（降为可选增强）、`crypto/` 的本机密钥方案。
- 不迁（旧仓留作参考实现）：G1–G7 决策树、Tauri 桌面壳与胶囊四态、Vue 三面板、扁平 JSON 持久化、"每日 80 格"预算模型。
- 栈：Rust 单二进制（core + CLI + git hook），npm 包只做平台二进制的下载器；桌面壳等 M2 有产物、且有人追问"有没有界面"时再挂回来。理由：§2.3 实测今天"除默认 GUI 主程序外无第二个 bin"，而无头 CLI 才是大众装机路径上唯一不需要解释的东西。
